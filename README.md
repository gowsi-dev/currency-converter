# Currency Converter

A simple currency converter that allows users to convert an amount from one currency to another only 5 currency are available now.

## How to Use

-> Enter amount to convert.
-> Select currency.
-> Select the target currency to convert.
-> Click convert button show the converted amount.

## Technologies Used

- HTML
- JavaScript
  
## What I Learned

- JavaScript DOM manipulation
- Handling button click events, select attribute change events
- Conditional statements
- Get input through id
- Object to store the currency value.
